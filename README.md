# 
# 🤖 Multi-Agent PR Review

**Automated, multi-perspective code review for GitHub Pull Requests using OpenAI and LangGraph**

---

## 🚀 Overview

This project provides an **AI-powered GitHub Pull Request review agent** that analyzes code changes with Security, Performance, and Maintainability agents, consolidates the findings, and posts an intelligent, actionable review as a PR comment.

---

## 🗺️ Architecture & Flow Diagram

```mermaid
flowchart TD
    GH[GitHub: Pull Request Event (opened/synchronize)] -->|Webhook| API[FastAPI Webhook Server]
    API -->|Verifies Signature| VAL[Validates Event]
    VAL -->|Fetches PR Data| AGENT[Main Review Agent]
    AGENT -->|Fetches Changed Files & Context| CONTEXT[Repo Context Gathering]
    CONTEXT -->|Collects Relevant Files| AGENTS[Multi-Agent Review]
    AGENTS --> SEC[Security Agent]
    AGENTS --> PERF[Performance Agent]
    AGENTS --> MAINT[Maintainability Agent]
    SEC --> JUDGE
    PERF --> JUDGE
    MAINT --> JUDGE
    JUDGE[Judge Agent (Synthesizes & Formats Review)] --> COMMENT[Comments on PR via GitHub API]
    COMMENT --> END[Done!]
```

---

## ⚙️ How It Works

1. **Webhook Event:**  
   GitHub sends a webhook when a PR is opened or updated.

2. **Signature Verification:**  
   The web server verifies the webhook's HMAC signature for security.

3. **PR Diff Fetch:**  
   Fetches the changed files/diffs & gathers related repo context (e.g. sibling/source/test files).

4. **Multi-Agent Review:**  
   - **Security Agent:** Finds secrets, injection risks, improper auth, etc.
   - **Performance Agent:** Detects N+1 queries, inefficient code, memory issues, etc.
   - **Maintainability Agent:** Flags breaking changes, name mismatches, test gaps, duplication, etc.

5. **Judge Agent:**  
   Consolidates findings, removes duplicates/speculation, sorts by severity, provides actionable suggestions.

6. **Automated Comment:**  
   Posts/updates a markdown review as a PR comment.

## 🏃‍♂️ Quickstart

### 1. **Install**

```bash
git clone https://github.com/humaila0/multi-agent_PR_review.git
cd multi-agent_PR_review
pip install -r requirements.txt
```

### 2. **Configure**

Create a `.env` with:
```env
GITHUB_TOKEN=your_github_token
OPENAI_API_KEY=your_openai_key
GITHUB_WEBHOOK_SECRET=your_webhook_secret
```

### 3. **Run Web Server**

```bash
uvicorn main:app --reload
```
Set your GitHub webhook to point to `http://your-server/webhooks/github` with your secret.

## 📁 File Structure

- `agent.py` — Core review logic & multi-agent system.
- `main.py` — FastAPI app/webhook handler.
- `requirements.txt` — Python dependencies.
- `.env` — Your secrets & API keys (not committed).

---

## 📦 Requirements

- Python 3.8+
- PyGithub
- FastAPI
- LangGraph, LangChain, python-dotenv
- Uvicorn (for serving API)

---

## 🛡️ Limitations

- Only analyzes visible code changes in PRs (does not build/run code).
- Quality of output depends on code structure and model quality.
- Token and API rate/billing limits apply.
